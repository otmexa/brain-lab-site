Example Structure

What each section should do

Example Goal

A site that is calm to read.

  • Clear menu at the top on every page.
  • Less filler text and less decorative clutter.
  • Each page should show only the content type it is meant to hold.

Example Flow

Home as orientation, not as a dump of everything.

The home page should explain what the lab publishes and guide visitors to the right section. It should not try to contain every interface option or every type of content at once.
